# 怎样看懂马来西亚的收据，一行一行讲

我以前都是把收据丢掉的。午餐 RM10，加油 RM15，一杯饮料 RM8，每一笔都觉得太小，不用管。后来我检查一星期的开销，发现不见了 RM200，到了月底钱包空空，我也说不出钱去了哪里。更麻烦的是，我的钱分散在好几间银行和电子钱包里。

所以我才开始认真看收据。收据会清清楚楚告诉你钱花去哪里，只是你要会看。

## 最上面：谁、什么时候

你会看到店名、地址、日期和时间。有注册 SST 的商家，通常也会在这里列出注册号码。日期很重要，因为你记账的时候，付钱那一天就是钱离开的那一天。

## 中间：买了什么

每一行是一样东西、数量和价钱。数量的写法不一样：`2 x 5.50`、`x2`，或者分成两行。看一下单价乘以数量对不对得上。

## 最下面的金额部分

这一块最多人跳过，但它正好解释了为什么合计比各项加起来更多。

| 项目 | 意思 |
|---|---|
| 小计 | 所有项目加起来，还没加费用 |
| 服务费 | 餐厅自己收的费用，通常 10% |
| SST | 税，餐饮是 6% |
| 凑整 | 调整到最接近的 5 仙，只针对合计 |
| 合计 | 你要付的钱 |
| 现金 / 卡 / 电子钱包 | 你的付款方式 |
| 找零 | 给的现金减去合计 |

例子：项目 RM21.00，服务费 RM2.10，SST RM1.26，加起来是 RM24.36。凑整后是 **RM24.35**。如果你给 RM30 现金，找零是 RM5.65。

凑整是针对整张账单的合计，不是每一项，这是国家银行和国内贸易及消费人事务部通告里订明的。至于为什么账单会比菜单贵，请看 [SST vs 服务费](/zh/sst-vs-service-charge)。

## 五个快速检查

1. **各项加起来等于小计吗？**写错一行是最常见的错误。
2. **服务费大约是小计的 10% 吗？**
3. **SST 是小计的 6% 吗？**如果高一点点，请看上面那篇文章。
4. **凑整很小吗？**最多 1 或 2 仙。
5. **合计和银行或电子钱包扣的钱一样吗？**对照一下手机上的通知。

想自己重新算一遍，可以用[账单计算器](/zh/bill-calculator)。

## 要保留哪些

以后可能用得上的收据，就拍照留着：有保养的商品、要报销的、金额大的。平常吃饭，记下金额和店名就够了。
